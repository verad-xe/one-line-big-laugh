One funny line, 200 characters or fewer, that lands entirely on its own — written for make.fun's "One Line, Big Laugh" bounty. Running `main.py` writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Run it

```sh
python3 main.py
```
